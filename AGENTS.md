- Phone number, home address, personal email (Gmail or similar)
- Grades, salary, visa status, date of birth
- Anything in `private/`: add it to `.gitignore` first; never commit or upload it
- Family details, newborn information, or other private life facts not on the CV

## Ask me first
- Before any `git push` or any change on GitHub
- Before deleting or overwriting a file
- Before enabling GitHub Pages or making the repo public
- Before adding tracking, analytics, or third-party scripts

- Professional and casual vibe
- Columbia blue as the accent color (`#75AADB` / `#002B7F` for headers)
- Streamlined navigation (sticky top bar, section anchors)
- Portfolio as a gallery page that links to each project (add later when asked)
- No frameworks required; single `index.html` is fine for the home page
- Do not invent jobs, dates, or awards; use only content from `cv.pdf` / approved sources
- Omit phone from the public page; contact via LinkedIn and GitHub (and CBS email if needed)

## When you finish
- Tell me what you changed and what you skipped
- List every file you created or edited
- Open the page locally in the browser; do not push until I say OK
